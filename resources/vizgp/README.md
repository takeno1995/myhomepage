# ガウス過程の可視化

`index.html` をブラウザで開くと動作します。ビルド、依存ライブラリ、外部CDN、計算サーバーは不要です。ホームページと同じ静的ホスティングに `resources/vizgp/` を配置できます。

HTTP で確認する場合は、リポジトリのルートで次を実行し、`http://localhost:8000/resources/vizgp/` を開きます。

```sh
python3 -m http.server 8000
```

- `gp.js`：カーネル、共分散、Cholesky分解、正規乱数、ガウス過程の条件付け。
- `app.js`：状態管理とSVG描画。サンプルパスは常に3本。
- `style.css`：PC・スマートフォン用のレイアウト。
- `tests.html`：ブラウザで開く数値計算・UIの回帰テスト。

操作パラメータはすべて図の上部に配置しています。幅900px以上では3段の図を連続表示し、ブラウザの表示領域の高さに合わせて各段の高さを調整します。右側の共分散行列は外部ライブラリを使わず、MathMLのdisplay形式で表示します。

選択した2点の周辺正規分布を左の関数図と右の同時分布の上・右に表示します。関数値方向のスケールは各軸と共通で、密度方向の高さのみ各曲線の最大値で正規化して収めます。マウス位置に対応する関数値の目印を左右・事前事後で共有し、関数や訓練データの再生成は行いません。

事前・事後で選ぶ2点と座標範囲は共通。訓練入力は `[0, 6]` の241点から重複なしで選択します。ターゲット関数も同じグリッドで生成するため、訓練観測は補間誤差を含みません。事後分布は潜在関数の分布で、予測観測ノイズを含みません。Cholesky分解には最大対角要素に対して通常 `1e-12` の相対ジッターを加え、必要な場合は段階的に増やします。事後共分散の差し引きに伴う丸め誤差には、事前共分散のスケールを使います。事前分散が全て0の場合は厳密に0を維持します。

自動再生成は1.5秒間隔で独立なサンプルを引き直します。ターゲット関数とデータは保持し、非表示タブでは再生成しません。カーネルの種類・パラメータ・和と積を変更するとターゲット関数と訓練データも更新します。スライダーの計算更新は操作を確定したときに行い、選択する2点は操作中も更新します。

参考：ST John による [Interactive Gaussian Process Visualization](https://github.com/st--/interactive-gp-visualization/)。カーネル6種類とそのパラメータ化を参考にし、日本語UI・SVG描画・数値計算をこのページ用に実装しています。

## 検証

HTTPサーバーを起動して `http://localhost:8000/resources/vizgp/tests.html` を開くと、数値計算8件・操作とレイアウト9件のテストを実行できます。解析式との比較、サンプルの経験共分散、全カーネルの和と積、ノイズ0、分散0、データ0件・40件、再生成とターゲット関数の保持、390px幅での表示、周辺分布と目印の双方向の対応などを確認します。

macOSでは数値計算のみをJavaScriptCoreでも検証できます。

```sh
/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc resources/vizgp/gp.js resources/vizgp/test-numerics.js
```
